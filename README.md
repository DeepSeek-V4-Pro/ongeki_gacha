# 音击抽卡模拟器

当前版本：1.2.0

反馈或咨询：[GitHub Issues](https://github.com/DeepSeek-V4-Pro/ongeki_gacha/issues)

一个基于 MaiBot 的本地娱乐抽卡模拟器，用于模拟音击卡牌收集与抽卡体验。

常见命令：

```text
/签到
/月卡
/抽卡 1
/抽卡 5
/抽卡 11
/抽卡 常驻
/点数
/奖励 @用户 <点数>（管理员）
/概率
/卡册
/卡图 <ID>
/卡池
/天井
/天井列表
/接任务 普通/挑战/终极 [音击/舞萌/中二]
/任务列表
/任务完成 <任务ID>
/任务审核 <任务ID> <普通/S/SS/SSS/SSS+/拒绝>（管理员）
/任务审核列表（管理员）
/终极完成 <用户> <任务ID>（管理员）
/规则
/帮助
```

插件默认按照历史官方 CARDMAKER 卡池每 15 天轮换，并应用卡池内 UP 权重；活动池按活动日期混入当期版本已有全部 R/SR/SSR 基础卡，再叠加官方 UP 与天井选择卡。官方公告未标注 UP 时，会显示 `UP 卡：0 张`，但这不代表池中没有候选，抽卡仍会使用当期版本已有基础卡。`/天井列表` 可查看当前池全部天井选择卡的 ID 与角色。可在配置中切换为按官方日期选池。另有常驻池，可用 `/抽卡 常驻` 单独抽取。`/卡池` 会同时发送当期官方活动图。

非抽卡来源卡不进入抽卡池，每日签到时按配置概率随机掉落。

抽卡结果图底部带 RinNET 风格的卡牌 ID 与卡号信息条；`/卡图` 只发送原始高清卡面，不带该信息条。

奖励采用“日常小额 + 7 天/15 天周期大额 + 月度加成 + 囤点档位（默认每 60 天重置）”的结构，适合长期签到和攒够点数后再抽。

随机任务默认从音击、舞萌 DX、中二节奏三游戏全量曲库中混合随机；也可以指定游戏：

```text
/接任务 终极 中二
```

普通/挑战任务由用户提交成绩照片后等待管理员人工审核；终极任务由管理员确认后发放奖励，完成后该曲不会重复抽取。
