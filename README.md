# 音击抽卡模拟器

当前版本：1.2.1

反馈或咨询：[GitHub Issues](https://github.com/DeepSeek-V4-Pro/ongeki_gacha/issues)

一个基于 MaiBot 的本地娱乐抽卡模拟器，用于模拟音击卡牌收集与抽卡体验。

常见命令：

```text
/签到
/月卡
/抽卡 1
/抽卡 5
/抽卡 11
/抽卡 常驻
/抽卡 <池ID> <数量>（official 模式指定启用中的卡池）
/点数
/奖励 @用户 <点数>（管理员）
/概率
/卡册
/卡图 <ID>
/卡池
/天井
/天井列表
/天井池 <池ID> <卡ID>
/接任务 普通/挑战/终极 [音击/舞萌/中二]
/任务列表
/任务完成 <任务ID>
/任务审核 <任务ID> <普通/S/SS/SSS/SSS+/拒绝>（管理员）
/任务审核列表（管理员）
/终极完成 <用户> <任务ID>（管理员）
/任务清理 [天数]（管理员）
/规则
/帮助
```

插件默认按照历史官方 CARDMAKER 卡池每 15 天轮换，并应用卡池内 UP 权重；活动池按活动日期混入当期版本已有全部 R/SR/SSR 基础卡，再叠加官方 UP 与天井选择卡。轮替起点会持久化到插件数据库，重启后继续原位置，不会回到第一期。官方公告未标注 UP 时，会显示 `UP 卡：0 张`，但这不代表池中没有候选，抽卡仍会使用当期版本已有基础卡。`/天井列表` 可查看全部启用池的天井选择卡 ID 与角色。可在配置中切换为按官方日期选池；official 模式可能同时启用多个卡池，`/卡池` 会列出全部，默认抽取最近开启的池，也可以用 `/抽卡 <池ID> <数量>` 指定其他启用池。另有常驻池，可用 `/抽卡 常驻` 单独抽取。`/卡池` 会发送各启用池的官方活动图。

当前官方排表只包含已抓取到的 63 个公告池，2023～2026 年仍有大量日常池缺失；official 模式适合作为已收录池的查看/抽取入口，暂不能视为完整官方时间线。

非抽卡来源卡不进入抽卡池，每日签到时按配置概率随机掉落，并发送对应卡面图。

抽卡结果图底部带 RinNET 风格的卡牌 ID 与卡号信息条；`/卡图` 只发送原始高清卡面，不带该信息条。

奖励采用“日常小额 + 7 天/15 天周期大额 + 月度加成 + 囤点档位（默认每 60 天重置）”的结构，适合长期签到和攒够点数后再抽。

随机任务默认从音击、舞萌 DX、中二节奏三游戏全量曲库中混合随机；也可以指定游戏：

```text
/接任务 终极 中二
```

普通任务任意难度；挑战任务会随机选出至少有一张 10 级或以上谱面的歌曲，
并选取该曲中达到门槛的最低真实谱面（例如舞萌 DX 的 `EXPERT DX 10`），
要求该谱面或以上取得 S；高难谱面是否游玩由玩家选择，不是必选项。
如果某首曲有多张 10 级或以上谱面（例如 `EXPERT DX 10` 与 `MASTER DX 12`），
就取其中最低的那张（`EXPERT DX 10`）作为目标，
不会强制选择曲目最高难度。
终极任务从谱面定数达到 14.7 或以上的超高难曲随机，要求 SSS+。
这里的 14.7 是内部定数阈值
（≥14.7），不是“14 级+”。

任务由用户提交成绩照片后等待管理员人工审核；已审核、已过期、已重置记录默认
保留 30 天，随后自动清理，管理员也可用 `/任务清理 [天数]` 立即清理；待审核任务
不会被自动清理。
