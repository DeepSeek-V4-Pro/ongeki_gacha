# 音击抽卡模拟器

**当前版本：1.3.0（2026-09-21）**

一个运行在 MaiBot 上的本地娱乐插件，用来模拟音击（オンゲキ）的抽卡、卡牌收藏、随机任务与主角色好感养成。
所有点数与物品都是模拟数值，不代表真实游戏资源。

## 特色

- **抽卡与卡池**：1 / 5 / 11 连，稀有度权重、UP 加权、周 5 连保底、11 连 SR 保底、常驻池与历史官方卡池；可按 15 天轮替（cycle）或按「几月几日」复现官方档期（official）。
- **天井**：按卡池独立累计，达到上限后可用卡池选择卡兑换，每个池一次。
- **点数经济**：签到、连续签到、7 天 / 15 天周期、月卡与半价五连、囤点档位奖励，签到还有 5% 概率掉落非抽卡收藏卡。
- **随机任务**：音击 / 舞萌 DX / 中二节奏三游戏曲库混合随机，普通、挑战、高级挑战、终极四档，成绩照片人工审核发奖。
- **主角色养成**：17 名主角色好感、基础 N 卡、奖励、称号与装饰、角色语音、解花与超解花。
- **图片化输出**：长内容自动排版成分页图片卡片，短回执直接发文字，渲染失败自动回退纯文本。
- **不依赖素材包**：发布包不含任何素材，插件在完全没有素材时也能以文字运行，见下。

## 素材与文字兜底

发布包只带代码、文档、工具和 JSON 索引，**不含卡面、界面素材、字体、养成图片与语音**。
需要这些素材时，用 `tools/` 下的接入工具把它接进本地 `assets/`；
素材从哪里获取请自行确认权利，说明见 [素材指南](ASSETS.md)。

没有素材时插件照常工作：

- 帮助、规则、卡池、卡册、任务、好感等长文本，用插件自绘的浅色渐变背景渲染成分页图片；
- 需要游戏素材的图（抽卡结果图、揭示图、`/卡图`、好感页、奖励页、解花对照图、任务卡）改为文字输出；
- 连系统中文字体都没有时，全部回复退化为纯文字。

```powershell
python -m ongeki_gacha.tools.verify_text_fallback   # 验证无素材包可运行
```

## 快速开始

1. 把插件目录放进 MaiBot 的插件目录（新版运行时为 `<MaiBot>/plugins/`）。
2. 在插件管理中加载，或重启实例。
3. 插件默认读取自身目录下的 `assets/card_data/`；也可以用配置指向外部素材目录。

首次加载会自动生成 `config.toml`，数据存放在插件数据目录的 `ongeki_gacha.db`。
需要 Pillow >= 11.3.0。

## 卡池与数据的边界

- 卡池排表来自 SEGA 官方 CARDMAKER 公告与 Artemis 的静态卡池数据，当前收录 63 个历史公告池，覆盖 2020-10 ～ 2026-07。
- 2023～2026 年仍有大量日常池未收录，official 模式是按「几月几日」复现已收录池的当年同期排期，不代表完整官方时间线。
- 活动池候选是“当期版本已有的全部 R/SR/SSR”再叠加本期 UP 与天井选择卡，与原作机台模型一致。
- 非抽卡来源卡不进入抽卡池，改为签到按概率掉落。
